# دليل الاستفادة الكاملة من Hermes Orchestrator
## أوركسترا الوكلاء المتوازيين بأفضل الموديلات المجانية

> **تاريخ الإنشاء:** 1 سبتمبر 2026  
> **الحالة:** نظام كامل شغال - 4 وكلاء + 5 Cron Jobs + 4 MCP + مهارتين مخصصتين

---

## 1. إيه اللي اتعمل عندك؟ (الوضع الحالي)

### أ. الوكلاء الأربعة (شغالين متوازي)
| الوكيل | دوره | حالته |
|--------|------|--------|
| 🤖 مهندس الأتمتة | بنى 5 Cron Jobs | ✅ خلص (134 ثانية) |
| 🔌 مهندس التكاملات | فعل 4 MCP + مشروع + Browser | ✅ خلص (395 ثانية) |
| 🧠 مهندس المعرفة | بنى الذاكرة + مهارتين | ✅ خلص (1447 ثانية) |
| ⚡ مهندس التحسين | فحص أمان + سكريبت صحة | ✅ خلص (908 ثانية) |

### ب. الـ 5 Cron Jobs (محفوظين وهيشتغلوا)
| # | الاسم | الموعد | الفائدة |
|---|-------|--------|----------|
| 1 | ☀️ التقرير الصباحي | يوميا 9:00 ص | يلخص جلساتك ومهامك أول ما تصحى |
| 2 | 📈 مراقب الأخبار | كل 3 ساعات | يجيب أهم أخبار التقنية والأسواق |
| 3 | 🧹 التنظيف الأسبوعي | جمعة 4:00 ص | ينضف الـ worktrees والـ checkpoints |
| 4 | 👀 مراقب المشاريع | كل ساعة | يتابع ملفاتك اللي اتغيرت |
| 5 | 🌙 المراجعة المسائية | يوميا 9:00 م | يراجع إنجاز اليوم ويقترح بكرة |

> **ملحوظة:** كلهم `active` لكن محتاجين `hermes gateway install` مرة واحدة عشان يشتغلوا والجهاز مقفول.

### ج. المهارات الجديدة
- **`free-model-orchestrator`** → تختار أنسب موديل مجاني لكل مهمة تلقائي (كود→deepseek، عربي→minimax، بحث→gemini، سريع→solar)
- **`orchestrator-ops`** → تدير الوكلاء المتوازيين بدون تضارب
- **القاعدة الثابتة:** البحث عن الجديد إجباري قبل أي رد **لو هيفيد فعلا** (مش بحث شكلي)

### د. التكاملات
- **MCP:** context7 (وثائق مكتبات) + notion + filesystem + github
- **المشروع:** `orchestrated-workspace`
- **السكريبتات:** `health-check.py` (فحص صحة) + `free-router.py` (تنقل تلقائي عند الليمت)

## 2. الاستفادة العملية - إزاي تستخدمه يوميا؟

### السيناريو 1: عايز بحث + تحليل (الأكثر استخداما)
```
أنت: "ابحث عن أفضل أدوات AI مجانية في سبتمبر 2026 وقيّمها"

اللي هيحصل تلقائي:
1. web_search (Firecrawl) → يجيب 5 مصادر حديثة
2. web_extract → يقرأ الصفحات كاملة
3. يختار gemini للتلخيص (أسرع) + deepseek للتقييم (أدق)
4. MoA (gpt-5.5 + deepseek → opus) يراجع ويجمّع
5. يسلّمك جدول مقارنة + توصية نهائية
```
**إفادتك:** رد مبني على معلومة طازة مش قديمة، وتقييم من كذا موديل مش واحد.

### السيناريو 2: عايز كود
```
أنت: "ابني لي API بايثون لإدارة مهام"

اللي هيحصل:
1. يقيّم: هل محتاج بحث؟ → نعم (يبحث عن best practices 2026)
2. يختار deepseek (أقوى للكود)
3. يكتب الكود + يختبره
4. MoA يراجع الأمان
5. لو deepseek وصل ليمت → ينتقل تلقائي لـ muse-spark
```
**إفادتك:** كود حديث + مراجع + مش هيقف عند ليمت.

### السيناريو 3: عايز محتوى عربي
```
أنت: "اكتب مقال عربي عن التسويق"

اللي هيحصل:
1. يقيّم: محتاج بحث؟ → نعم (إحصائيات 2026)
2. يبحث → يختار minimax (أفضل عربي)
3. يكتب + solar يراجع اللغة
```
**إفادتك:** عربي سلس + معلومة حديثة.

## 3. GitHub Pages - النشر المجاني الدائم

### إيه هو؟
موقع مجاني على `https://ahmedkamalsa.github.io/hermes-orchestrated` يعرض شغل الوكلاء حتى لو جهازك مقفول.

### ليه Pages مش سيرفر؟
| | GitHub Pages | سيرفر (Fly/Render) |
|---|---|---|
| **التكلفة** | مجاني للأبد | مجاني محدود ثم مدفوع |
| **الشغل** | عرض تقارير/لوحات/مواقع ثابتة | تشغيل بوت يرد 24 ساعة |
| **الـ Cron** | عبر GitHub Actions (2000 دقيقة مجانا) | عبر gateway شغال دايما |
| **المناسب ليك** | ✅ حاليا (نشر نتائج) | لما تحتاج بوت تليجرام 24 ساعة |

### إزاي تستفيد منه؟
1. **الوكلاء يكتبوا تقرير** → يعملوا `git push` للـ repo
2. **GitHub Actions** يبني الموقع تلقائي
3. **انت تفتح اللينك** من أي جهاز وتشوف النتيجة بدون ما تفتح Hermes

**مثال عملي:**
- الوكيل "مراقب الأخبار" يجيب أخبار كل 3 ساعات → يكتب `news-2026-09-01.md` → يرفعه → يظهر في موقعك كصفحة أخبار متجددة
- لوحة التحكم اللي شفتها هتبقى لايف على Pages

## 4. التنقل عند الليمت - مش هتحس بعقبة

### المشكلة القديمة:
موديل واحد يوصل `429 Rate Limit` → الرد يفشل → انت تستنى.

### الحل الجديد (`free-router.py`):
```
طلبك → أجرب muse-spark → ليمت؟ → deepseek → ليمت؟ → solar → gemini → minimax
                                    (كل نقلة ثانية واحدة، تلقائي)
```
**إفادتك:** عمر ما طلب هيفشل بسبب ليمت. الوكيل هيحاول 5 موديلات ورا بعض قبل ما يقولك "حاول بعد دقائق" (نادر جدا).

### مع القاعدة الثابتة:
البحث عن الجديد + التنقل عند الليمت = **أقصى استفادة فعلية** مش شكلية. لو البحث مش هيفيد → أوفر وقتك، لو هيفيد → أجيب طازة وأنتقل بين موديلات لحد ما أسلّم.

## 5. التدخل المطلوب منك (مرة واحدة بس)

### الآن (دقيقة واحدة):
```bash
# 1. تفعيل الـ Cron التلقائي (اختياري لكن مهم)
hermes gateway install
# → يثبت Task يشتغل مع الويندوز، حتى لو قفلت الشات

# 2. تفعيل Notion لو بتستخدمه
hermes mcp login notion
# → يفتح متصفح تسجل دخول مرة واحدة

# 3. تأكيد GitHub Pages (هنعمله مع بعض)
# → هتدخل repo settings → Pages → تختار branch: main
```

### بعدها - صفر تدخل:
- أي طلب في الشات → البحث + اختيار الموديل + التنقل تلقائي
- أي Cron → يشتغل لوحده ويحفظ في `hermes cron history`
- أي نشر → الوكلاء يعملوا push وPages تتحدث

**هتتعلم مرة، وبعدها الأيجنت + وكلاءه شغالين بأقصى استفادة وأنت مش بتعمل حاجة.**
