## ملاحظات سريعة

### كيف تختار؟
- **تريد أوتوميشن فقط:** n8n + Activepieces
- **تريد AI محلي مجاني 100%:** Ollama + Open WebUI + AnythingLLM
- **تريد Backend كامل مجاني:** Supabase + NocoDB + PocketBase (خفيف)
- **تريد استضافة كل شيء على سيرفر واحد:** Coolify أو Dokploy على Hetzner CX22 ($4.30/شهر)

### تكلفة الاستضافة الذاتية المقدرة (Self-Host)
| المكون | الحد الأدنى | ملاحظات |
|--------|-------------|---------|
| Coolify | 2 vCPU / 4GB RAM | Apache-2.0 مجاني |
| Supabase كامل | 4 vCPU / 8GB RAM | 15+ container |
| Ollama + Open WebUI | 8 vCPU / 16GB RAM + GPU مستحسن | للـ LLM المحلي |
| n8n | 1 vCPU / 1GB RAM | خفيف جداً |
| PocketBase | 0.5 vCPU / 512MB | ملف واحد! |

> **نصيحة Hermes:** ابدأ بـ `Coolify على Hetzner ($5-8/شهر)` وشغّل n8n + Supabase + Ollama معاً — يغنيك عن Zapier ($30) + Firebase ($25) + ChatGPT Plus ($20) = **توفير ~$75/شهر**.

### الترخيص
- MIT/Apache-2.0 (تجاري مسموح): Ollama, Coolify, Dokploy, PocketBase, AnythingLLM, Activepieces, LangChain, Open WebUI
- Fair-code (اقرأ الشروط للاستخدام التجاري الكبير): n8n
- AGPL/Apache مزدوج: Supabase, NocoDB

## خطة ربط مقترحة مع Hermes orchestrator

```
[Hermes Core] 
   ├─→ n8n (webhooks + cron) ─→ Gmail/Telegram/Sheets
   ├─→ Ollama (localhost:11434) ─→ LLM مجاني لكل Skills
   ├─→ Supabase (Postgres) ─→ ذاكرة دائمة + Realtime
   ├─→ NocoDB (فوق Supabase) ─→ لوحة تحكم بشرية
   ├─→ AnythingLLM (RAG) ─→ ابحث في ملفات المستخدم قبل الإجابة
   ├─→ Open WebUI ─→ واجهة مستخدم بديلة لـ Hermes Chat
   └─→ Coolify ─→ نشر الكل بنقرة على VPS واحد
```

> **الخطوة التالية:** اختر 2-3 مشاريع للبدء (مقترح: n8n + Supabase + Ollama) وأنشئ `docker-compose.yml` موحد عبر Coolify.
