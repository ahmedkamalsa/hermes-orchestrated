## استراتيجية Hermes Orchestrator — كيف تجمع الـ 15 معاً بلا دفع

### التوزيع المقترح (يومياً مجاناً بالكامل)

```
Gemini 2.5 Flash (1000 RPD)  →  المهام الأساسية + RAG
Gemini Flash-Lite (1000 RPD) →  الـ batch والتصنيف
Groq Llama 8B (14,400 RPD)   →  الـ high-throughput / function calling
Groq Llama 70B (1000 RPD)    →  الـ reasoning السريع
OpenRouter Free (1000 RPD)   →  الـ overflow والـ fallback
HuggingFace ($0.10)          →  النماذج النادرة (DeepSeek, Qwen)
Mistral (1B tokens/شهر)      →  الكود (Codestral)
Replicate (free runs)        →  الصور/الصوت
Whisper Groq (2000 RPD)      →  التفريغ الصوتي
```

**المجموع النظري المجاني:** ~18,000+ طلب نصي/يوم + 8 ساعات تفريغ + صور + 1B توكن Mistral — كلها بلا بطاقة (باستثناء OpenRouter $10 الاختياري الذي يرفعك لـ 1000 إضافية).

### 5 قواعد لتعظيم كل ليمت

1.  **لا تكرر المفاتيح في نفس الحساب** — الحصة على مستوى الحساب/المؤسسة، ليس المفتاح. بدلاً من ذلك: وزّع عبر **مزودين مختلفين** (Gemini + Groq + OpenRouter = 3 حصص منفصلة).
2.  **الـ TPM هو القاتل الصامت** — في Groq 6000 TPM تعني رسالة طويلة واحدة (4000 توكن) تستهلك 66% من دقيقتك. قصّ السياق، فعّل الـ caching، واستخدم Flash-Lite للطويل.
3.  **فشل الطلب يُحتسب** — في OpenRouter كل 429 يخصم من الـ 50/1000. أضف `retry-after` + exponential backoff ولا تعيد المحاولة فوراً.
4.  **Developer بلا تكلفة = 10×** — في Groq أضف بطاقة (صفر حد أدنى) → 300K TPM و 1000 RPM بدلاً من 6K/30. نفس الشيء لـ Google: ربط فوترة يرفعك من 100 إلى 10,000 RPD.
5.  **راقب الـ headers** — كل مزود يرسل `x-ratelimit-remaining-requests` و `x-ratelimit-reset`. اقرأها قبل كل دفعة بدلاً من التخمين.

### تسلسل الـ Fallback الموصى به (كود)

```python
# free-router-v2.py — تسلسل مقترح
PRIMARY = "google/gemini-2.5-flash"          # 1000 RPD مجاناً
FALLBACKS = [
    "groq/llama-3.1-8b-instant",             # 14,400 RPD — الأعلى
    "openrouter/auto:free",                 # يختار أفضل free متاح
    "mistral/codestral-latest",             # 1B tokens/شهر
    "huggingface/deepseek-ai/DeepSeek-R1",  # عبر HF $0.10
]
```
